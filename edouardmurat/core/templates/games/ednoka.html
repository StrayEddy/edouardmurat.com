EdNoKa "Study Through Gaming" Platform

EdNoKa is a free educational gaming platform. Players answer quiz questions to progress through five games in five different genres.

Pick a quiz, then play it in whichever game you like. Farming, mini golf, a hack-and-slash: the quiz stays the same and the game around it changes. How well you know the material is what moves you forward.

Play the free Steam demo Visit EdNoKa's Website

Why I Built It

Studying and playing were always kept apart when I was growing up. Studying was supposed to be serious and solitary. Games were what you did afterwards, if you had earned them.

I never accepted that split, and EdNoKa is my argument against it. The quiz is not a gate in front of the game or a score at the end of it. It runs inside the game, and answering is how you play. Dodge a missile, plant a crop, sink a putt: the questions are part of the loop either way.

That is a larger claim than gamification, which usually means points and badges bolted onto homework. Here the subject matter is the mechanic.

The Quizzes

The quiz sets come with the game and I wrote them. Pick one, pick a game, and its questions reach you inside whatever you are playing. The same set works in all five, so the subject stays put while the genre changes around it.

Behind the Scenes

I built almost all of EdNoKa myself, from the game design through to the servers it runs on. What that covered:

Game Development

  • • Designed and built five games across five genres in Unity and Godot, 2D and 3D
  • • Wired the quiz into the game loop: multiple-choice questions arrive often, and the answer changes what happens next
  • • Wrote the quiz sets that ship with the game

Backend & Infrastructure

  • • Built the Django REST API, the database layer and the authentication
  • • Deployed and run the production servers on Ubuntu and Nginx
  • • Built the coin-based in-game store on Steam, Google Play and the App Store

Testing & Feedback

  • • Tested it on Windows, Mac, Linux, Android and iOS
  • • Ran a beta and watched streamers play it live

Design & Promotion

  • • Made every promotional asset: the trailers, the logos, the animated explainers, the Steam page and the website

All of it is one person's work, from the game design down to the nginx config.
