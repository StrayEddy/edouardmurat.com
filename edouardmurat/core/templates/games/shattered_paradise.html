Shattered Paradise Roguelike

A turn-based, grid-based dungeon crawler roguelike where death is permanent and every run shapes the next.

Retrace Dante's path through Inferno, Purgatory, and Paradise as you explore procedurally generated worlds ruled by a false god. Originally titled Paradise Lost, built under the studio name One More Turn Studios.

Core Design Pillars

  • • Turn-based, grid-based combat
  • • Procedural dungeons with persistent world state
  • • Procedural loot
  • • Handcrafted world map and NPC hubs
  • • Heavy narrative integration through mechanics
  • • Deep character customization
